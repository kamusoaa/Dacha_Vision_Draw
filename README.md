# dacha_vision_draw

Сервис рисует рамки обнаруженных объектов на фото для проекта «Дача 2.0».

## Переменные окружения

| Переменная | Значение |
|---|---|
| `DRAW_TOKEN` | токен доступа; «Элемент» передаёт его в заголовке `Authorization: Bearer <токен>` |

## API

`GET /ping` — проверка доступности, ответ `200`.

`POST /draw` — рисует рамки.

Запрос:

```json
{
  "image": "<фото в Base64>",
  "boxes": [
    {"label": "Человек 87%", "class": "person", "box_2d": [100, 200, 900, 600]}
  ]
}
```

`box_2d` — `[ymin, xmin, ymax, xmax]` в шкале 0–1000.
`class` — `person`, `cat` или `dog`. Класс задаёт цвет рамки.

Ответ: `{"image": "<фото с рамками в Base64, JPEG>"}`.

Ошибки: `401` — неверный токен, `400` — битое фото, `422` — неверный формат запроса или рамки, `503` — не задан `DRAW_TOKEN`.
