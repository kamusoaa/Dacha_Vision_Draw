# dacha_vision_draw

Сервис рисует рамки обнаруженных объектов на фото для проекта «Дача 2.0».
Сервис также собирает файлы Excel с группировкой строк для проекта «Проверка кодов ASL BELGISI».

## Переменные окружения

| Переменная | Значение |
|---|---|
| `DRAW_TOKEN` | токен доступа; «Элемент» передаёт его в заголовке `Authorization: Bearer <токен>` |

## API

`GET /ping` — проверка доступности, ответ `200`.

`POST /draw` — рисует рамки.

Запрос:

```json
{
  "image": "<фото в Base64>",
  "boxes": [
    {"label": "Человек 87%", "class": "person", "box_2d": [100, 200, 900, 600]}
  ]
}
```

`box_2d` — `[ymin, xmin, ymax, xmax]` в шкале 0–1000.
`class` — `person`, `cat` или `dog`. Класс задаёт цвет рамки.

Ответ: `{"image": "<фото с рамками в Base64, JPEG>"}`.

Ошибки: `401` — неверный токен, `400` — битое фото, `422` — неверный формат запроса или рамки, `503` — не задан `DRAW_TOKEN`.

`POST /xlsx` — собирает файл Excel с группировкой строк. Адрес использует тот же `DRAW_TOKEN`.

Запрос:

```json
{
  "sheet": "Лист_1",
  "header_fill": "F2F2F2",
  "collapsed": true,
  "columns": [
    {"title": "Код маркировки", "width": 53.75, "kind": "text"},
    {"title": "Количество", "width": 16.25, "kind": "number"}
  ],
  "rows": [
    {"level": 0, "values": ["00031003762997753772", "72"]},
    {"level": 1, "values": ["0114780010153257217!zkn+/w,Nh2_", "6"]},
    {"level": 2, "values": ["0104780010153250217!(U34h", ""]}
  ]
}
```

| Поле | Значение | По умолчанию |
|---|---|---|
| `sheet` | имя листа, до 31 символа | `Лист_1` |
| `header_fill` | цвет шапки, шесть шестнадцатеричных цифр | `F2F2F2` |
| `collapsed` | скрыть строки с уровнем больше 0 | `true` |
| `columns[].title` | заголовок колонки | обязателен |
| `columns[].width` | ширина колонки | ширина Excel |
| `columns[].kind` | `text` — текст, `number` — строка превращается в число | `text` |
| `rows[].level` | уровень группировки, от 0 до 7 | `0` |
| `rows[].values` | значения строки, только строки; число значений равно числу колонок | обязателен |

Колонки `text` получают формат «Текст»: коды с ведущими нулями не превращаются в числа.
Пустая строка в колонке `number` даёт пустую ячейку. Итог группы стоит над вложенными строками.

Ответ: `{"file": "<xlsx в Base64>", "rows": <число строк>}`.

Ошибки: `401` — неверный токен, `400` — значения не совпадают с колонками, значение не число, недопустимый символ или имя листа, `413` — больше 200 000 строк или тело больше 50 МБ, `422` — неверный JSON или формат запроса, `503` — не задан `DRAW_TOKEN`. Тело ошибки: `{"detail": "текст"}`.

### Память

Сервис разбирает запрос `/xlsx` и собирает файл в отдельном процессе. Процесс завершается после сборки, и система забирает его память. Одновременно идут не больше двух сборок.

Замер на 25 657 строках: сборка около 1,3 с, файл 557 КБ. Основной процесс: 50 МБ в покое, 60 МБ после первой сборки, без роста за 15 сборок.
